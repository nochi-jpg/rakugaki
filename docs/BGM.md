# BGM

## いまの BGM：内蔵の チップチューン（`js/bgm.js`）

- 音声ファイルを 使わず、**譜面データ（MML）を その場で 鳴らす**。むかしの 携帯ゲーム機ふうの 4チャンネル（矩形波×2・低音の三角波・ノイズのドラム）。
- 9きょく ぜんぶで 約15KB なので、Canva版の 10MB制限に ひびかない。曲は ぜんぶ オリジナル。
- ぜんぶ くりかえし（ループ）で 鳴る。「かち」「まけ」は はじめの 2小節（ファンファーレ）の あと、4小節を くりかえす。
- せってい →「おんがくを きく」で 9きょくを ためしに 鳴らせる。「おんがく」で 切れる。
- ブラウザの きまりで、さいしょに がめんを さわるまでは 鳴らない。

| 名前 | 流れる ところ | テンポ・調 | ふんいき |
|---|---|---|---|
| `title` | タイトル | 150・ハ長調 | あかるい マーチ |
| `story` | さいしょの おはなし | 84・イ短調 | しずかで すこし ふしぎ |
| `home` | ホーム・モンスター・ほうせき・じゅんび・せってい | 116・ト長調 | のんびりした まち |
| `make` | モンスターを つくる | 100・ハ長調 | ゆったり・じゃまに ならない |
| `shop` | おみせ | 132・ヘ長調 | はずむ |
| `solve` | もんだいを とく 60秒 | 156・ニ短調 | はやめ・集中（音量は 小さめ） |
| `watch` | なぐりあいを 見る | 172・イ短調 | たたかい |
| `win` | けっか：かち・ひきわけ・ともだちとの たいせん | 150・ハ長調 | ファンファーレ → あかるい |
| `lose` | けっか：まけ | 96・イ短調 | しょんぼり → やさしい |

## 曲を 直す・足す

`js/bgm.js` の `C.TRACKS` に、1小節ごとの 文字列で 書いてある（書き方は ファイルの 先頭）。
`lead`＝メロディ、`sub`＝和音、`bass`＝低音、`drum`＝ドラム。小節の 長さが 合わないと `node tools/tutorial_test.js` が 知らせる。

## 音声ファイルに さしかえたい とき

`assets/bgm/<名前>.mp3`（`.ogg`・`.m4a` でも よい）を 置いて `python3 tools/build.py --canva` を 動かすと、**その曲だけ** ファイルの 音に なる。
1ファイル版には うめこまれるので、容量に 注意（いま 約5.3MB。10MBまで）。
